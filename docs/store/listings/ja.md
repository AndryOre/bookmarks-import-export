# Chrome Web Store listing: ja

## Title

Snug: ブックマークの書き出し・読み込み・バックアップ

## Summary

ブックマークをHTML・JSON・CSVで書き出し、読み込み、自動バックアップ。すべて端末内で完結し、アカウントもクラウドも不要です。

## Detailed description

Snugは、ブックマークをブラウザ間で、そのままの状態で移せる拡張機能です。どこにも送信されず、アカウントも不要です。

ブックマーク全体でも、選んだフォルダだけでも、HTML、JSON、CSVで書き出せます。読み込みはまずプレビューで確認してから、既存のブックマークと統合するか、まるごと置き換えるか、新しいフォルダにまとめて入れるかを、その都度選べます。

スケジュールを一度設定すれば、Snugがブックマークを「ダウンロード」フォルダに自動でバックアップします。形式と間隔はお好みで選べます。ファイル名に日時を自動で含められるので、前回のファイルと混ざったり、上書きされたりすることもありません。

Snugはすべて端末内で動作します。アカウントもクラウドもサーバーも不要です。どの操作も、ブラウザ自身のブックマークの読み取りと書き込みだけで完結します。信頼の根拠は、それがすべてです。Chromeのほか、Chromiumベースのブラウザ（Edge、Opera、Brave）でも、同じ掲載ページから利用できます。
