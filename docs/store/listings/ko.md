# Chrome Web Store listing: ko

## Title

Snug: 북마크 내보내기·가져오기·백업

## Summary

북마크를 HTML, JSON, CSV로 내보내고 가져오며 자동 백업까지. 모든 작업은 기기
안에서만 처리되고 계정도 클라우드도 필요 없어요.

## Detailed description

Snug는 북마크를 브라우저 사이에서 있던 그대로 옮겨 주는 확장 프로그램이에요.
어디로도 전송되지 않고, 계정도 필요 없어요.

북마크 전체든 직접 고른 폴더든 HTML, JSON, CSV로 내보낼 수 있어요. 가져올 때는
먼저 미리보기로 확인한 다음, 기존 북마크와 병합할지, 통째로 교체할지, 새 폴더에
한꺼번에 담을지 그때그때 직접 정하세요.

일정을 한 번만 설정해 두면 Snug가 북마크를 다운로드 폴더에 알아서 백업해요.
형식과 간격은 원하는 대로 고를 수 있어요. 파일 이름에 날짜와 시간을 자동으로
넣을 수 있어서 이전 파일과 헷갈리거나 덮어쓰이는 일이 없어요.

Snug는 모든 것을 기기 안에서 처리해요. 계정도, 클라우드도, 서버도 필요 없어요.
모든 작업은 브라우저 자체의 북마크를 읽고 쓰는 것이 전부예요. 신뢰의 근거는 바로
그것뿐이에요. 같은 스토어 페이지에서 Chrome은 물론 Chromium 기반 브라우저(Edge,
Opera, Brave)에서도 사용할 수 있어요.
