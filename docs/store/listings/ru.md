# Chrome Web Store listing: ru

## Title

Snug — экспорт, импорт и резервные копии закладок

## Summary

Экспорт, импорт и резервное копирование закладок по расписанию — HTML, JSON или
CSV, на вашем устройстве, без аккаунта и облака.

## Detailed description

Snug переносит ваши закладки между браузерами в том виде, в каком вы их
оставили: ничего никуда не отправляется, аккаунт не нужен.

Экспортируйте всё дерево закладок или только выбранную папку — в HTML, JSON или
CSV. При импорте сначала показывается предпросмотр, а затем вы решаете сами:
объединить с имеющимися закладками, полностью их заменить или поместить всё в
новую папку — каждый раз выбор за вами.

Настройте расписание один раз, и Snug сам будет сохранять копии ваших закладок
прямо в папку «Скачанные файлы» — в нужных вам форматах и с нужным интервалом.
Имена файлов могут автоматически включать дату и время, чтобы ничего не
перезаписывалось и не путалось с предыдущей копией.

Snug работает целиком на вашем устройстве: без аккаунта, без облака, без
сервера. Каждая операция читает и записывает данные прямо в дерево закладок
вашего браузера — вот и вся история о доверии. Работает в Chrome и в любом
другом браузере на основе Chromium (Edge, Opera, Brave) — всё с одной страницы в
магазине.
