# Chrome Web Store listing: zh_CN

## Title

Snug：书签导出、导入与备份

## Summary

导出、导入书签，并定时自动备份——支持 HTML、JSON 或 CSV，全程在本机完成，无需账号，无需云端。

## Detailed description

Snug 可以在浏览器之间迁移你的书签，保持原样——不向任何地方发送，也无需账号。

你可以导出整个书签树，或只导出选定的文件夹，格式可选 HTML、JSON 或 CSV。导入时先预览，再决定：与现有书签合并、直接全部替换，或统一放进一个新文件夹——每次都由你决定。

只需设置一次计划，Snug 就会按你选择的格式和间隔，自动把书签备份到“下载内容”文件夹。文件名可以自动包含日期和时间，因此不会覆盖，也不会与上一次的备份混淆。

Snug 完全在你的设备上运行——没有账号，没有云端，没有服务器。每项操作都只是读取和写入浏览器自己的书签，这就是信任的全部依据。除 Chrome 外，也适用于其他基于 Chromium 的浏览器（Edge、Opera、Brave），同一个商店页面即可安装。
